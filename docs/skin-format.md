# 皮肤格式说明

> Beautype 皮肤系统（v1.0 已实现）：两种图片模式 + 默认可视化配置，通过设置面板上传与调整，保存即时生效。

## 1. 皮肤模式

| 模式 | 效果 | 图片规格 |
|---|---|---|
| **默认**（mode=none） | 纯色 / 渐变候选框 + 颜色 / 字体 / 字号 / 圆角 / 布局可视化调整 | 无需图片 |
| **角色图**（mode=role） | 候选框右侧站一个角色，角色**固定不变形** | 建议 256×256 PNG 透明底 |
| **输入框图**（mode=frame） | 整个候选窗变成上传图片的造型（非矩形），候选 / 上屏 / 翻页 / 选词功能不变 | 建议 600×200 PNG：左右各 150px 不变形，中间 300px 拉伸 |

两种图片模式可叠加或替换：角色图 = 叠加在右侧；输入框图 = 替换整个矩形 UI。**功能链路（候选、上屏、翻页、选词）与皮肤模式无关，只换 UI 样式**。

## 2. 九宫格规则（输入框图）

上传图按两条水平切线与两条垂直切线切成 **9 段**（默认切线 `borders: {left:150, right:150, top:40, bottom:40}`）：

```
┌──────────┬─────────────────────┬──────────┐
│  左上角   │      上边(拉伸)       │  右上角   │  ← 固定高 40
│ 固定     │                     │ 固定     │
├──────────┼─────────────────────┼──────────┤
│  左边     │      中间(双向拉伸)    │  右边     │  ← 文字区嵌此
│ 固定     │  候选字/高亮块在此区    │ 固定     │
├──────────┼─────────────────────┼──────────┤
│  左下角   │      下边(拉伸)       │  右下角   │  ← 固定高 40
│ 固定     │                     │ 固定     │
└──────────┴─────────────────────┴──────────┘
  ← 150 →        ← 300 →          ← 150 →
```

- **四角（4 块）**：原尺寸绘制，永不变形（角色 / 装饰所在区域）
- **上 / 下边（2 块）**：水平拉伸，垂直方向固定（建议放纯色 / 可重复纹理）
- **左 / 右边（2 块）**：垂直拉伸，水平方向固定
- **中间（1 块）**：双向拉伸；候选文字与高亮块渲染其上
- 上传非 600×200 图片时可手动调整切线

## 3. theme.yaml（主题配置）

皮肤配置存于 `%APPDATA%\Beautype\config\theme.yaml`：

```yaml
name: default
colors:
  background: "#F5F5F0"
  text: "#333333"
  highlight_text: "#111111"
  highlight_background: "#E6E6DE"
font:
  family: "Microsoft YaHei"
  size: 16
layout:
  padding_x: 8
  padding_y: 6
  item_spacing: 2
  item_height: 22
  max_items: 8
skin:                      # 皮肤块（可选；缺省 = 默认模式）
  mode: none               # none | role | frame
  role_image: role.png     # 角色图（相对 theme.yaml 目录）
  frame_image: frame.png   # 输入框图（相对 theme.yaml 目录）
  borders:                 # 九宫格切线（frame 模式用）
    left: 150
    right: 150
    top: 40
    bottom: 40
  text_region:             # 文字排版区（相对整图左上角；缺省 = 中间区）
    x: 170
    y: 70
    width: 260
    height: 60
```

- `text_region` 缺省规则：`x = left 切线`，`y = top 切线`，`width = 图片宽 - left - right`，`height = 图片高 - top - bottom`（即整个中间区），文字在其内按 `layout.padding_*` 缩进排版
- 图片上传时自动拷贝到主题配置目录并填相对文件名

## 4. 渲染规则（候选窗）

| 模式 | 窗口尺寸 | 绘制 |
|---|---|---|
| none | 现有逻辑 | 纯色 / 背景 + 颜色字体（默认可视化配置） |
| role | 现有矩形尺寸 + 右侧角色槽宽 | 原 UI 照旧，右侧固定区绘制角色图（缩放至槽高、等比不变形） |
| frame | 宽 = left + 中间区宽 + right；高 = top + 中间区高 + bottom | 9 段绘制：四角原尺寸、上 / 下水平拉伸、左 / 右垂直拉伸、中间双向拉伸；文字 / 高亮块画在 text_region 内 |

中间区宽 = 候选内容宽（由候选字数与 layout 计算），窗口随候选变化在中间区拉伸——左右安全区（角色 / 装饰）永不变形。高亮块、候选文字、翻页箭头全部画在 `text_region` 内，坐标相对整图左上角。

## 5. 操作入口

设置面板 → **自定义皮肤**：

| 操作 | 动作 |
|---|---|
| 上传角色图片 | 选 PNG → 校验（建议 256×256）→ 拷贝到主题目录 → `skin.mode=role` + `skin.role_image` → 预览缩略图 |
| 上传输入框图片 | 选 PNG → 校验（建议 600×200）→ 拷贝到主题目录 → `skin.mode=frame` + `skin.frame_image` + 默认 borders → 预览缩略图 |
| 恢复默认 | 清 `skin` 块（mode=none），颜色 / 字体 / 布局回默认 |
| 保存并应用 | 写 theme.yaml + 热更新候选窗（无需重启） |

## 6. 扩展点（不在 v1.0）

- 搜狗 `.ssf` 皮肤包兼容：搜狗皮肤包 = skin.ini + 多张 PNG/APNG，.ssf 实为 zip 改后缀；落地方式为新增 `SsfImporter`（拆包 → 解析 → 产出本 theme.yaml schema），不推翻现有架构
- 动态模型预览面板（3D/2D 模型统一预览）：后续"模型管理"模块，与本模块解耦
